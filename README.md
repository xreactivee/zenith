# zenith

zenith — lightweight desktop application built with javascript and electron.

## Features
- Professional hotkey remapping and keyboard customization through Electron IPC handlers
- Local application scanning and icon extraction via PowerShell scripts
- Local user authentication, profile management, and configuration persistence
- Lightweight and fast execution with cross-platform support and system tray integration

## Tech Stack
- JavaScript
- Electron
- HTML5 & CSS3

## Installation
```bash
git clone https://github.com/xreactivee/zenith.git
cd zenith
npm install
```

## Usage
```bash
npm start
```
